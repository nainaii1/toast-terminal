# The Bill, Posted

One farmer's real cost of a perp DEX point, week by week, over 90 days (01 Oct to 31 Dec 2026).

**Read it:** https://nainaii1.github.io/toast-terminal/

- Each points week as a receipt: trading spread, other trading costs, points earned, cost per point.
- What other farmers on a public X list say a point costs them, each linked to their own post. Their claims, not checked.
- How the bill is counted.

The page is rebuilt from my own trade records and pushed here automatically when a number changes.
It is a cost record, not a result and not financial advice.
